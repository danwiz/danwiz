## GitLab sequencing

GitHub is authoritative. A secondary GitLab project should mirror a selected public repository one-way, with a dedicated minimal-scope credential only after the GitLab account and access are confirmed. Never enable bidirectional mirroring or move private code as part of this public portfolio setup.
